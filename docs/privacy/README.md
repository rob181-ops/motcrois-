# Politique de confidentialité (URL à mettre sur Google Play)

Ce dossier contient une page **publique** (HTML) à publier via **GitHub Pages**.

## Publier via GitHub Pages (gratuit)

1) Pousse ce repo sur GitHub (ou un repo dédié).
2) Dans GitHub : `Settings` → `Pages`
3) `Source` : *Deploy from a branch*
4) `Branch` : `main` (ou `master`) et `Folder` : `/docs`
5) Attends la publication.

L’URL de ta page privacy sera :

`https://<ton-user>.github.io/<ton-repo>/privacy/`

C’est cette URL que tu colles dans Google Play Console → “Règles de confidentialité”.
